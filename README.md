# 🎁 Amigo Secreto Familiar

Aplicación web responsiva y privada para el sorteo del **Amigo Secreto Familiar** de **Lucy, Mami, Chayo y Jerlin**.

## ✨ Características

1. **🔒 Consulta Privada con PIN de 4 dígitos:**
   - Cada participante tiene su PIN personal para revelar a quién le tocó regalar sin que nadie más lo espíe.
   - Botón para ocultar inmediatamente el secreto tras consultarlo.
2. **🕵️ Modo Detective (Ayuda Memoria):**
   - Si la hermana (Jerlin) o cualquier familiar olvidó a quién le tocó regalar, puede probar nombres de candidatos.
   - **Feedback ROJO**: Alerta roja y animación en caso de equivocarse.
   - **Feedback VERDE**: Alerta verde esmeralda y celebración con **confeti** festivo cuando acierta.
3. **📱 100% Responsivo y Mobile-First:**
   - Adaptado para verse perfecto en celulares iPhone/Android y en computadoras.
   - Teclado numérico automático para el ingreso de PINs en pantallas táctiles (`inputmode="numeric"`).
   - Tarjetas Glassmorphism con efectos Tailwind CSS.
4. **💾 Almacenamiento Local (LocalStorage):**
   - Guarda los secretos directamente en el navegador de manera persistente.

## 🚀 Despliegue en Vercel

Este proyecto es un sitio estático (`index.html`) listo para ser importado en Vercel con 0 configuración.
